## 📌 Project Overview

At **Polygnan**, we believe India's youth should become the kind of builders who don't just prepare for the future of work — but help shape it (Think Rancho from *3 Idiots*). 

The **EYFI (Earn Your First Income) Challenge** challenges college students across India to earn however they want in under 30 days. This platform serves as the interactive **EYFI Campus Ambassador & Gamified Reward Pathway Hub**, designed to recruit, verify, and gamify the journey of campus Scouts across 100+ Indian universities.

---

## ✨ Key Features & Highlights

### 🏆 1. Gamified 6-Level Reward Pathway & 3D Swiping Card Deck
- **Step 0 Prerequisite (`Step 0: Apply & Get Verified`)**: Entry point requiring Scout application submission before unlocking Level 1.
- **Levels 1 to 6 Milestones**:
  - **Level 1 (Scout Title)**: 0 Regs — Initial Scout Rank & LinkedIn Credentials
  - **Level 2 (Campus Ambassador)**: 25 Regs — Ambassador Certificate & Swag Kit
  - **Level 3 (Level Up & Swag)**: 50 Regs — Custom Tech Box & VIP Hackathon Pass
  - **Level 4 (Go Further)**: 75 Regs — ₹15,000 Event Sponsorship Grant
  - **Level 5 (Paid Internships)**: 100 Regs — Monthly Performance Stipend & Direct Hiring Referrals
  - **Level 6 (Founding Team)**: 200 Regs — Full Equity Core Team Consideration & Founders Retreat
- **Frosted Glass Lock Overlays**: Locked cards display a `backdrop-blur-md` frosted glass overlay with quick-unlock buttons that dynamically unblur when registration thresholds are met.
- **Custom Color Themes**: Tailored neon glows for every level (`Emerald`, `Lime`, `Cyan`, `Gold`, `Orange`, `Violet`, `Imperial Gold`).

### 🌐 2. Interactive 3D College Cards Globe (*"Real scouts, real campuses."*)
- Rotates a 3D sphere of verified Indian university cards (`IIT Bombay`, `IIM Ahmedabad`, `SRCC`, `BITS Pilani`, `Loyola`, `Manipal`, `Symbiosis`, `Christ Bglr`, `NIT Trichy`, etc.).
- Built using **Fibonacci Sphere Lattice Mathematics** with continuous 3D drag/touch rotation, perspective scaling, and real logo fallbacks.

### 🪪 3. Interactive Scout Pass Studio
- Live customization of personalized ambassador passes with custom full name, campus name, and level rank previews.
- Features holographic card aesthetics, verified status badge, QR code, and one-click copyable pass sharing links.

### 🐦 4. Animated Flying Bird Silhouette
- Real-time 60FPS randomized flight steering algorithm with sine-wave swooping and flapping wing keyframes soaring across the dark dot-grid canvas.

### 🤖 5. Poly AI Agent Assistant
- Floating bottom-right AI agent widget (`Poly`) providing instant conversational answers to EYFI Challenge rules, 30-day earning ideas, and ambassador applications.

### 🎨 6. Premium Visual Aesthetics
- Continuous dark dot-grid background (`bg-dots-pattern`), smooth glow highlights, Space Grotesk & Bricolage Grotesque typography, and 0 solid dark box blockages.

## 🚀 Quick Start & Installation

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / yarn / pnpm

### 1. Clone the repository
```bash
git clone https://github.com/Praveen-ing/Polygnan-Assignment.git
cd Polygnan-Assignment
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000/` or `http://localhost:5173/`.

### 4. Build for Production
```bash
npm run build
```
